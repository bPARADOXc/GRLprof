# Data Directory

Place local merged KGQA data here.

Expected examples:

```text
data/webqsp_may_merged/train.json
data/webqsp_may_merged/validation.json
data/webqsp_may_merged/test.json
data/webqsp_may_merged/webqsp_paths_gte_modernbert_base_train.pt
```

Full datasets and generated `.pt` embeddings are intentionally ignored by git.
