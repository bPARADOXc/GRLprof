# Notice

GRLprof reorganizes and extends code from:

- LLaGA: Large Language and Graph Assistant
- SubgraphRAG: Simple Yet Effective KG-Based RAG

The adapter model class keeps `llaga` model-type names for checkpoint and tokenizer compatibility. The released project name, documentation, and output prefixes use `GRLprof`.

License files from upstream components are preserved in `licenses/`:

- `licenses/LLAGA_LICENSE`
- `licenses/SUBGRAPHRAG_LICENSE`

When publishing checkpoints or datasets, include the upstream citations and any dataset-specific license terms.
